Sign in to Bluesky

Sign in with an app password, not your main password. Create one on bsky.app under Settings → Privacy and security → App passwords.

Make a new app password just for this page (for example, name it “Catch-up”). Don't reuse one from another app, and leave “Allow access to your direct messages” unchecked; this page doesn't need it. If anything ever seems off, you can revoke that one password without affecting anything else.

About this page and your privacy
  • Where this page comes from. It's an open-source project by choccy. The source, the full change history and every past version live on GitHub — you're running version . It's free to use, copy and change under the MIT licence. Found a bug, or want something it doesn't do? Open an issue.
  • You can keep your own copy. The whole thing is one HTML file: download version (or just save this page) and open it straight from your disk. It works exactly the same, needs no server or install, and keeps working even if this site ever goes away. Everything is in that one file, documentation included: how it works, every setting and the full history of changes are written as a comment at the top, so you can open it in any text editor and read it.
  • It runs entirely in your browser. There's no server behind this page. It connects to your own account's server (where your password is sent, and nowhere else), to an AppView for reading feeds and threads — by default whichever one your account's server uses, or any other you name under Settings → Advanced — and to that AppView's picture and video hosts. Signing in may also ask the site your handle is named after, a DNS-over-HTTPS resolver (Cloudflare's unless you change it) and the did:plc directory, to work out which server holds your account; naming that server yourself skips all three. Only when you play a video, it also fetches the video player library from jsDelivr. The typeface and the icon are built into the file, so nothing else is ever fetched.
  • Why a separate app password, then? Because the page is a file that can be copied and edited, a unique password limits the damage if a copy was ever tampered with or your computer is compromised. App passwords can't change your password or email, or delete your account, and you can revoke each one individually.
  • “Stay signed in” stores a sign-in token, not your password, in this browser's local storage for this file. Settings and your reading position are stored there too. Uncheck it on a shared computer, and use “Sign out” when you're done.
  • Likes and reposts are real. They're posted to your actual account and are public, just as if you'd done them on bsky.app.
  • Only use a copy from someone you trust. If someone sent you this file, you're trusting them not to have changed it. The code is plain, commented HTML and JavaScript, so anyone technical can open it in a text editor and check it — and you can always compare it against, or just use, the official copy at bsky-catch-up.choccy.gay.
  • Open the file directly in your browser. Previews (for example, inside a chat app or email) usually block the connections it needs. Recent versions of Chrome, Firefox, Edge and Safari all work.
  • This isn't an official Bluesky app. It's an independent tool using Bluesky's public API, and it isn't affiliated with or endorsed by Bluesky. If something breaks, use bsky.app as usual.
